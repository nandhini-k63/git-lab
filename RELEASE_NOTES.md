# Visual Studio Code – Release Notes

**Version:** 1.104  
**Release Date:** September 11, 2025  
**Release Type:** Feature and Maintenance Update

## Overview

Visual Studio Code version 1.104 introduces improvements to AI-assisted development, security, terminal functionality, and the overall editing experience.

## New Features

- **Automatic Model Selection (Preview):** Introduced an option that automatically selects an AI model for Chat.
- **AGENTS.md Support (Experimental):** Added support for project-specific instructions to provide context to AI agents.

## Security Improvements

- **Sensitive File Protection:** Added confirmation before AI agents modify certain sensitive files.
- **Terminal Command Approval:** Improved controls for automatically approving terminal commands.

## Improvements

- Improved the changed-files interface in Chat to make reviewing edits easier.
- Enabled terminal sticky scrolling by default.
- Added additional ways to open terminals in separate windows.

## Bug Fixes

- Addressed an issue where terminal sticky scroll could briefly appear while navigating through a pager.

## Notes

Some AI-related features are experimental or in preview and may require supported extensions or accounts.
